# Widgets

Versailles does not own the live desktop. You keep HTML under `Documents\Widgets`. This repo is the host plus templates and examples.

Put tiles in `article.widget` and overlays in `template.spawnable` inside `desktop/index.html`. Do not iframe per-widget folders.
